# 🧮 Java Calculator

A sleek desktop calculator application built with **Java**, featuring a modern dark-themed UI with orange accent buttons — inspired by the iOS calculator style.

---

## ✨ Features

- **Basic Arithmetic** — Addition, Subtraction, Multiplication, Division
- **Square Root** — One-tap `√` operation
- **Percentage** — Quick `%` conversion
- **Sign Toggle** — Flip between positive and negative with `+/-`
- **All Clear** — Reset everything instantly with `AC`
- **Decimal Support** — Precise decimal point input
- **Responsive Display** — Large, readable number display at the top

---

## 🎨 UI Overview

| Button | Function |
|---|---|
| `AC` | Clear all input |
| `+/-` | Toggle positive / negative |
| `%` | Convert to percentage |
| `√` | Square root of current value |
| `÷` `×` `-` `+` | Standard arithmetic operators |
| `=` | Evaluate the expression |
| `.` | Decimal point input |

The interface uses a **dark grey** base with **orange** operator buttons for a clean, modern look.
